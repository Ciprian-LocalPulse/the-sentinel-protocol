## Other Ways to Help (Free)

Financial support is entirely optional. Just as valuable:

- ⭐ Star the repository
- 🐛 Report bugs or suggest features via GitHub Issues
- 🔀 Contribute code, schemas, or prompt specifications — see [CONTRIBUTING.md](CONTRIBUTING.md)
- 🧭 Flag a place where an implementation risks drifting from the
  [Design Philosophy](https://github.com/Ciprian-LocalPulse/the-sentinel-protocol/wiki/Design-Philosophy)
  constraint — anything that could let a component fabricate urgency,
  scarcity, or a claim not backed by real evidence
  (mark it `philosophy-violation` — these are treated as highest priority)
- 📚 Help build out the reference prototype, test suite, or
  integration adapters — see [Roadmap and Status](https://github.com/Ciprian-LocalPulse/the-sentinel-protocol/wiki/Roadmap-and-Status)
  for open items
- 📣 Share the project with founders, automation engineers, or teams
  building context-aware communication tooling
