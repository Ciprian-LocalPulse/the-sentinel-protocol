# Papers

## `sentinel-whitepaper.pdf`

The original conceptual document — the vision, in the author's own voice,
including the positioning/pricing analysis. This is the *pitch*; `docs/`
is the *specification an engineer implements from* (see
[`../docs/philosophy.md`](../docs/philosophy.md)).

Where the engineering specification in `docs/` diverges from a mechanism
described in this whitepaper, `docs/philosophy.md` documents exactly
where and why — the whitepaper is preserved unedited as the historical
source document, not silently revised to match the final architecture.

## Reading Order

New readers: start with the repository [`README.md`](../README.md) and
[`docs/architecture.md`](../docs/architecture.md) for the engineering
view. Read this whitepaper afterward for the full original vision and
business framing.
