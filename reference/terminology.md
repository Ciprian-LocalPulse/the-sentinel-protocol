# Reference — Terminology

See also [`docs/glossary.md`](../docs/glossary.md) for pillar-level terms.
This document covers action-level terminology used across prompt specs and
code.

| Term | Definition |
|---|---|
| **Draft** | Content generated by the Persona pillar, always requiring founder review before it becomes a **Send**. |
| **Send** | An action that actually transmits a message. Never automatic by default — see `docs/design-principles.md` §2. |
| **Auto-send** | An explicit, opt-in configuration per channel/context that skips the review step for a defined category of low-risk messages (e.g., meeting-confirmation replies). Off by default. |
| **Score** | Any numeric output from Cortex, Energy, or Negotiation modules — always paired with `factors` and an `explanation` field. |
| **Tier** | The P1–P5 priority classification (`docs/cortex/scoring.md`). |
| **Mask** | A tone/register preset (`docs/persona/masks.md`) — never alters factual content. |
| **Capacity Score** | The founder's own, 0–1 estimated decision-making capacity (`docs/energy/biometrics.md`). |
| **Focus Mode** | The workload-pacing state triggered by high fatigue (`docs/energy/decision-fatigue.md`). |
| **Leverage Score (Lv)** | The negotiation-strength estimate (`docs/negotiation/algorithms.md`), built only from real, sourced inputs. |
| **Audit Log** | The append-only local record of every score, draft, and capacity check (`docs/security/privacy.md`). |
