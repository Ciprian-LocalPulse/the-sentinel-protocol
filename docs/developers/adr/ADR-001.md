# ADR-001: Reframe Deceptive Mechanisms From the Original Whitepaper

**Status:** Accepted
**Date:** 2026-07-31

## Context

The original whitepaper specified three mechanisms that alter a third
party's beliefs about reality without their consent: fabricated calendar
events ("Calendar Hijacking"), covert response-delay penalties ("punish
toxic clients"), and fabricated negotiation pretexts ("I have withdrawn
the resource allocation..."). Each served a legitimate underlying goal
(focus protection, fair prioritization, honest urgency signaling).

## Decision

Implement the underlying goals honestly instead: real, accurately-labeled
Focus Mode calendar blocks; transparent SLA tiers; scarcity signals that
return `null` unless a real, sourced constraint exists.

## Consequences

- **Positive:** The system's outputs are always true, which makes them
  durable — nothing breaks if a counterparty ever investigates a claim.
  See `docs/negotiation/pricing.md#why-the-calendar-entry-change-matters-technically-not-just-ethically`
  reasoning (mirrored in `docs/philosophy.md`).
- **Negative:** Some negotiation leverage that relied on fabricated
  urgency is no longer available. This is treated as an acceptable
  trade-off, not a gap to work around.
- **Neutral:** The core mathematics (leverage score, priority score) is
  unchanged — only what's allowed to feed those formulas changed.

## Alternatives Considered

- **Ship as specified, with a disclaimer.** Rejected — a disclaimer does
  not change what the deployed system actually does to the people it
  interacts with.
- **Make deception opt-in/configurable.** Rejected — see `GOVERNANCE.md`
  on why this boundary is a project invariant, not a per-deployment
  toggle.

Full mapping of changed mechanisms: [`docs/philosophy.md`](../../philosophy.md).
